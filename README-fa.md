# CurlyBot App 🤖 (خاکستری × قرمز)

اپ اندروید که `curlybot.py` خودت رو (بدون هیچ تغییری) روی گوشی اجرا می‌کنه.

## ساخت APK از روی گوشی (بدون اندروید استودیو)
1. توی گیت‌هاب یه ریپوی جدید بساز (مثلاً `CurlyBot-App`).
2. تمام فایل‌های این پوشه رو (با پوشه‌ی `.github`) آپلود کن.
3. تب **Actions** ← **Build APK** ← **Run workflow**.
4. بعد از ~۵ تا ۱۰ دقیقه، پایین صفحه‌ی اجرا بخش **Artifacts** ← `CurlyBot-APK` رو دانلود کن (zip)، بازش کن و `app-debug.apk` رو نصب کن.

## استفاده
- تنظیمات: آیدی روم + توکن ربات + **یوزرنیم مالک** (بدون @) رو وارد کن ← ذخیره. هرکسی یوزرنیمش رو اینجا وارد کنه، مالک ربات می‌شه.
- خانه: دکمه‌ی گرد قرمز = روشن/خاموش.
- لاگ: گزارش زنده‌ی ربات.
- راهنما: لیست دستورها با جستجو و دسته‌بندی؛ روی هر دستور بزنی کپی می‌شه.
- «اجازه بده» توی تنظیمات رو بزن تا اندروید ربات رو نکشه.
- ربات با نوتیفیکیشن ثابت و WakeLock آنلاین می‌مونه و اگه اندروید سرویس رو بکشه خودش دوباره بالا میاد.

## نکته
- موزیک/رادیو روی گوشی کار نمی‌کنه (ffmpeg نداره)؛ بقیه‌ی دستورات کار می‌کنن.
- کد ربات: `app/src/main/python/curlybot.py` — هر وقت عوضش کردی، فایل رو جایگزین کن و دوباره Build بزن.
